# Té o Café / Mundo Té o Café — E-Commerce Chile 🇨🇱

Plataforma de comercio electrónico y tostaduría digital orientada al mercado chileno, con soporte de despacho para Santiago (Región Metropolitana) y todas las regiones del país.

## 🚀 Características Principales

- **Brand & UI Studio en Vivo**: Selector interactivo superior que permite alternar en tiempo real entre:
  - **Variantes de Marca**: *Té o Café*, *Café o Té*, *Mundo Té o Café*, *TeoCafé*.
  - **Paletas de Color**: *Tostaduría & Ámbar*, *Matcha & Botánica*, *Artisan Terracota*, *Minimalist Noir & Gold*.
  - **Tipografías**: *Playfair Display* (Editorial gourmet), *Plus Jakarta Sans* (Moderno), *Cinzel* (Clásico).
- **Base Operativa Oficial Integrada (138 Productos)**:
  - **La Finca**: Tés de hoja noble e infusiones (Kunal Rooibos, Té Chai verde, Alyssa, Ivy, Earl Grey, Begonia, Azalea).
  - **La Finca**: Cafés artesanales recién tostados (Valle del Cauca, Quindío, Dual Dark, Liofilizado, Packs Sensoriales, Cápsulas).
  - **Té Basilur Chile**: Catálogo completo de tés Ceylán, pirámides, latas de colección, teteras y sets de regalo.
  - **Café de Colo-Colo**: Café instantáneo, café Centenario, cápsulas Nespresso, prensas francesas y cafeteras.
- **Carrito de Compras Chileno Completo**:
  - Tarifador dinámico: RM ($2.990 / Gratis sobre $30.000) y Regiones ($4.990 vía Starken/Chilexpress).
  - Simulación de Checkout con medios de pago chilenos: **Webpay Plus (Transbank)**, **Mercado Pago**, **Transferencia bancaria**.
- **Vista Rápida (Quick View)** y selector de variantes de molienda y peso en tiempo real.

## 📦 Despliegue en GitHub Pages

Este proyecto está construido como una aplicación web moderna sin dependencias complejas de servidor para pruebas inmediatas y demostración en GitHub Pages.
